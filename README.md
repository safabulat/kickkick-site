# deskick-site

The published landing page for **Deskick**, a macOS desk toy.
Live at <https://safabulat.github.io/deskick-site/>.

This repository is a **mirror**. The source of truth is `site/` in the private app repository, and
`tools/publish-site.sh` overwrites this one from it — edits made here get lost on the next publish.
There is no application code here, only the page.
